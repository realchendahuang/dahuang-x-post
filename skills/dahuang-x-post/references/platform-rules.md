# Platform Rules

只在用户问字符数、媒体、编辑、长帖、Articles、账号套餐或发布限制时读取。

## 使用原则

- 不假设用户是 Premium，也不假设账号拥有 Longer Post、Edit 或 Articles。
- 不把某次看到的字符数、媒体数量或编辑窗口写成永久规则。
- 用户需要精确数字时，先查当前 X Help / X Business 官方页面，再按账号实际界面确认。
- 用户只要改文案时，不为平台限制额外加载本文件。

## 写作层面的稳定规则

- 先把核心信息写清楚，再决定短帖、Thread 或 Article。
- Hashtag、emoji、媒体和 CTA 都是可选项，只在服务内容时使用。
- 外链不能替代正文价值；先说明链接解决什么问题。
- 图片避免堆满文字；视频应让静音观看者也能理解。
- Thread 每条推进一个观点、步骤或证据，避免把长文机械切片。
- Article 优先移动端阅读：短段落、明确小标题、论点后尽快给证据。

## 风险边界

不承诺推荐、曝光或涨粉。避免：

- 重复文案刷屏。
- 误导性标题或伪造结果。
- 空互动诱导。
- 无关 hashtag 和 emoji 装饰。
- 为制造争议而篡改事实。

平台功能发生变化时，只更新本文件中的当前事实，不把易变数字复制进 \`SKILL.md\`。
